🤖 COWORK AGENT AI cron 0 8 * * *

Cấu hình ở cowork/COWORK_TASK.md. Mỗi lần chạy xử lý tối đa 5 keyword và 5 outline.

Bước 0 - Nhịp tim:

POST /heartbeat báo đang chạy. Dashboard báo đỏ nếu quá 26 giờ không có nhịp.

Phần A - Lập outline:

GET /keywords ➔ phân tích đối thủ bằng serp_keyword.py ➔ 2-3 key ngắn + 2-3 key dài ➔ outline (title dưới ~60 ký tự, H2/H3, FAQ 5 câu) ➔ POST /outlines kèm report_md. Nếu có góp ý của người duyệt thì làm đúng từng ý.

Phần B - Viết bài:

GET /outlines/approved ➔ viết đúng 100% key phụ, chạy evaluate_seo.py đến ≥ 90, meta 150-160 ký tự, không để link trong bài ➔ lưu seo_output/<slug>/ ➔ tạo Google Docs trong thư mục Drive ➔ POST /articles kèm google_doc_url.

Phần C - Gợi ý làm mới bài cũ:

GET /refresh-candidates (bài giảm clicks hoặc tụt hạng, tối đa 3 bài/lần) ➔ so với đối thủ ➔ báo lên chuông 2-4 việc nên sửa. Chỉ đề xuất, không tự sửa bài đã đăng.

Báo lên chuông Dashboard:

Mỗi lỗi: mức error / warning. Cuối lần chạy: success ("Đã đẩy N outline, M bài"), info nếu không có keyword mới. Lỗi tạo Docs không làm dừng lần chạy.
