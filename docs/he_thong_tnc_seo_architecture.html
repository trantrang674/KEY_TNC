Sơ Đồ 2: Cấu Trúc File/Thư Mục & Vai Trò Trách Nhiệm

Mỗi file và thư mục chịu trách nhiệm một phần việc chuyên biệt trong chuỗi cung ứng nội dung SEO.

📁 backend/ (Trọng tâm logic)
  • engine.py: Trung tâm phối hợp (Orchestrator). Chấm điểm (thang 100), tuyển Top 20 Keyword và 5 bài viết hay nhất cho từng key.
  • news_fetcher.py: Quét dữ liệu RSS từ 11 trang tin & đối thủ trong 48h, bóc tách ngày giờ phát hành.
  • classifier.py: Phân loại keyword theo cụm chủ đề (Linh kiện, AI, Game, HĐH, Sự kiện) và Brand (Nvidia, Intel, Apple...).
  • serpapi_client.py: Quản lý 4 API SerpApi, cơ chế gọi đúng 1 lần/ngày và cache cục bộ để tiết kiệm quota.
  • seo_suggester.py: Phân tích bài viết & Google Autocomplete để gợi ý 3 tiêu đề/từ khóa phụ viết bài.
📁 frontend/ & 📁 data/
  • frontend/index.html: Giao diện Web Dashboard SPA hoàn chỉnh (Tailwind CSS). Xem báo cáo, lọc nhóm ngành, phân tích chỉ số, duyệt bài.
  • frontend/logo.png: Logo thương hiệu TNC.
  • data/latest_top10_report.json: File JSON lưu báo cáo Top 20 mới nhất.
  • data/serpapi_daily_*.json: Cache kết quả 4 cổng SerpApi theo từng ngày.
  • data/workflow.json: Lưu trạng thái duyệt và bài viết ở chế độ chạy offline.
📁 database/ & 📁 supabase/
  • database/auth_postgres.sql: Bảng và chính sách RLS cho người dùng Supabase Auth.
  • database/admin_only_users.sql: Phân quyền chỉ tài khoản được Admin duyệt mới xem được báo cáo.
  • database/seo_content.sql: Bảng chứa keyword duyệt, outline và bài viết SEO của Cowork.
  • database/zalo_messages.sql: Bảng lưu thông báo Zalo.
  • supabase/functions/cowork-api: API Edge Function cho Cowork AI tương tác.
  • supabase/functions/zalo-webhook: Webhook gửi tin nhắn thông báo sang Zalo Bot.
📁 cowork/ & Root Files
  • cowork/COWORK_TASK.md: Bản hướng dẫn cấu hình và Prompt cho Agent AI tự động lập outline & viết bài.
  • build_static.py: Script tạo site tĩnh cho GitHub Pages và đẩy báo cáo vào Supabase.
  • tests/test_core.py: Unit tests kiểm tra tính đúng đắn của logic khớp keyword và tính thời gian tươi.
  • .env: Lưu SerpApi Key và thông số Supabase bí mật.
📁 .github/workflows/daily-pages.yml (Tự Động Hóa CI/CD)
Workflow GitHub Actions tự động kích hoạt vào lúc 12:00 trưa giờ VN (05:00 UTC) vào các ngày thứ 2, thứ 4, thứ 6 hoặc kích hoạt thủ công bằng nút "Run workflow". Nó chạy build_static.py, gọi các cổng API cần thiết, nạp báo cáo mới lên bảng daily_reports của Supabase và đẩy bản giao diện tĩnh cập nhật lên GitHub Pages.

Sơ Đồ 3: Chu Kỳ Vận Hành Tự Động Hóa Nội Dung (End-to-End Workflow)

Trực quan hóa cách 1 từ khóa tin tức được phát hiện, người biên tập duyệt, và Cowork Agent AI triển khai viết bài.
